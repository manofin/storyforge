# StoryForge / Seutolipoji

Korean-first interactive story UI (Next.js App Router + TypeScript + Tailwind).
Original placeholder content only.

## Scripts (package.json)

- dev: local development server on port 3000
- build: production build
- start: serve production build

Install packages, then run the dev or build script.

## Routes

- / story chat (archive, chat list, suggested replies, mock AI)
- /character discovery chips + cards
- /works filters, empty/create, samples
- /image library, prompt, style cards
- /search tabs + filtered catalog
- /api/chat mock replies (optional OpenAI key)

## Design

- Light theme + red accent (#E11D2E)
- Desktop ~1280px, Korean UI first
